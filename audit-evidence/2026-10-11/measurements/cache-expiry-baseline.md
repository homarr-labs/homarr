# Serialized Custom Widget cache baseline

This was the first authorized production-source baseline run. It used the original harness with 5 cycles, 25 responses per cycle, 1-second TTL, and 100 ms idle margin, with `--expose-gc`. The executor source SHA-256 was `708233b47f082780818c62823d81b9f849aaecacfe5e566879f637cffe56f167` (`packages/custom-widgets/src/server/request-executor.ts`). Runtime was Node `v25.1.0`; process arguments were `--expose-gc --import tsx`. Requests traversed the real executor and parser to the synthetic server on 127.0.0.1. The harness passed cache-hit, expiry-refetch, refreshed-hit, and in-flight invalidation checks.

Raw JSON-lines output is in `cache-expiry-baseline.jsonl`. The observed heap-used values were 23.69–25.35 MB at populated samples and 23.96–25.30 MB after TTL plus idle. The flat populated/idle heap values are consistent with retained expired entries; this run is inconclusive, not evidence against retention. It lacked an empty baseline and explicit-invalidation sample, so it cannot attribute that memory to cache entries. External memory varied more, including roughly 11–12 MB at some populated samples and 4.64 MB at idle, while ArrayBuffers stayed at 140,555 bytes. RSS did not drop at the idle samples.

The process resource usage is emitted on the first line of the JSONL. `/proc/self/limits` at collection time reported unlimited CPU time, data size, resident set, and address space; stack soft limit 8,388,608 bytes; open files soft/hard 1,024/1,048,576; process soft/hard 256,000/256,000; locked memory 8,399,298,560 bytes; core size 0. Other listed limits were unlimited except msgqueue 819,200 bytes and pending signals 256,000.

This run cannot determine whether expired entries account for the observed heap. Its Node 25 runtime also differs from the repository-pinned Node 24 and makes it unsuitable as the paired baseline for the revised protocol. Do not interpret the lower external-memory idle samples as proof of retained-cache cleanup. No production change had been made when this initial baseline was collected; the later Node 24 baseline and timer implementation are documented in `cache-expiry-results.md`.
