## Finding: `app.selectable` returns an unused `pingUrl` for every app

**Problem and trigger.** The first time a consumer observes `clientApi.app.selectable`, the server returns the complete selectable-app list. The API projection includes `pingUrl` for each app (`packages/api/src/router/app.ts:118-155`). The UI package's selector directly calls this query (`packages/modals-collection/src/apps/app-select-modal.tsx:27-60`), but neither the selector's cards nor its callbacks read `pingUrl`. Its concrete callers are the board add-app action, whose callback uses only `app.id` (`apps/nextjs/src/app/[locale]/boards/(content)/_edit-actions.tsx:56-72`), and the integration edit selector, whose form's `app` schema contains only `id`, `name`, `iconUrl`, and `href` (`apps/nextjs/src/app/[locale]/manage/integrations/edit/[id]/_integration-edit-form.tsx:47-55, 314-350`).

The same endpoint is shared by app widget selection, bookmarks, the board selection toolbar, new integration selection, and Spotlight's authenticated catalog (`packages/widgets/src/_inputs/widget-app-input.tsx`, `packages/widgets/src/bookmarks/add-button.tsx`, `apps/nextjs/src/components/board/selection/board-selection-toolbar.tsx`, `apps/nextjs/src/app/[locale]/manage/integrations/new/_integration-new-form.tsx`, and `packages/spotlight/src/lib/catalog.ts`). Inspection of these consumers found no `pingUrl` read; they use app identity and display fields such as name, icon, href, and description. Spotlight can keep the query observed during the authenticated session. When an observer goes away, the query cache's default GC window is five minutes (`packages/api/src/query-cache.ts:13`; applied by `apps/nextjs/src/app/[locale]/_client-providers/trpc.tsx:131-135`).

**Cause and dimensions.** The shared selectable endpoint exposes a full app field that its current consumers do not need. Removing it reduces response transfer and the corresponding query-cache/client object footprint in proportion to the number of apps and the serialized ping URL lengths. It does not reduce server query row count or the UI's rendered app-card count. No production app-count, response-byte, or heap measurement was collected, so the absolute savings are unknown.

**Smallest compatible fix.** Remove `pingUrl` from the `selectable` output projection and DB `columns` in `packages/api/src/router/app.ts`; update the OpenAPI description to omit ping URLs. The separate app detail/create/update endpoints retain their ping URL fields. This keeps all inspected selectable consumers' needed fields intact. Tradeoff: any external consumer relying on the documented selectable endpoint's ping URL would need a separate detail lookup; no in-repository consumer does so.

**Complexity, confidence, and gaps.** Low implementation complexity; high confidence that the in-repository UI callers do not use this value. The app result list has no API limit, so the reduction scales with account app count. Validate actual bytes before/after for representative small and large app sets, and inspect the query cache/heap after fetching and after its five-minute inactive GC window if sizing the runtime impact is needed. No runtime measurements were made.

## Other lifecycle and payload review

The modal provider renders the current modal and any stacked parent explicitly marked `keepMounted`; the reducer removes a closed entry. Thus closing ordinary modals releases their component state, and repeated open/close does not accumulate modal instances. This includes the app selector's `createdApps` state and the request-media modal's query-derived table state. The icon picker search is capped at 24 icons per repository by its server query; the six configured repositories bound the blank-search browse to at most 144 options. It creates image/option nodes only for those results, and uses no object URLs or global listeners. Its caller-side form state and preview are released with the containing form/modal.

The reviewed temporary listeners and timers have cleanup paths: `FloatingTip` clears show/dismiss timers, `InlineConfirmAction` removes document listeners and its timeout, and `SearchInput` delegates debounce lifecycle to Mantine's hook. Upload handling uses `FormData` over the selected `File` values and does not create object URLs. No other actionable retained-data, repeated-payload, optional-editor import, or cleanup issue was supported by the inspected call paths. Bundle or CSS transfer measurements were not performed, so package barrels and global stylesheet imports are not reported as size findings without chunk evidence.
