# Decisions and scope

This document supersedes provisional impact wording in inspection reports. Measurements use the baseline in `baseline.json` and synthetic fixtures; dimensions not measured remain unmeasured. Measurements and focused validation are complete. Two independent read-only reviewers inspected the full final source diff and relevant callers; neither found an actionable issue.

## Supported and retained

1. **Project linked integration items to board IDs.** Actual middleware and media-search authorization consume only `item.boardId`. SQLite/Drizzle nine alternating pairs per 1/25/250 linked widgets show 250-widget serialized DB rows 8,243,961 to 19,821 B, held GC heap delta 8,272,328 to 32,944 B and warm query median 21.12 to 3.46 ms. DB-result bytes are not HTTP bytes. Downstream output/authorization match. Work/space scale changes from O(N*S) option bytes to O(N) IDs; count remains O(N). No steady RSS or PostgreSQL result is claimed. Released-query cycles show small bookkeeping/runtime drift, not option-sized retention.

2. **Disconnect LDAP clients on failed authorization.** Service and user clients close in finally; secondary cleanup errors preserve original failure. Nine real ldapts/TCP synthetic-peer pairs show 151 failed service binds retain 151 client handles before and zero after at every cumulative stage. Baseline handles continue to grow over the measured attempts; after does not. Same-process peer contributes memory, preventing a production byte claim. Cleanup adds protocol work and failed-bind p95 is noisier/slower (0.492 to 0.705 ms); success/live-directory latency is unmeasured.

3. **Generate a compact Custom JSX runtime catalog.** Canonical authoring/public JSON remains byte-identical. All 475 descriptors, 479 resolved aliases, 4,311 binding cases and required props match. Actual production Turbopack graph confirms the full catalog leaves the renderer closure: raw renderer chunk 871,041 to 234,629 B; gzip-oriented estimate 92,566 to 19,256 B. Full authoring data remains on the lazy edit path. Editor opening can load/retain both catalogs (editor heap unmeasured); both chunks together add 229,829 raw / 17,278 gzip-oriented estimated B for editor users. Isolated esbuild registry browser fixture nine pairs show actual Brotli response body 50,112 to 11,917 B and post-GC heap delta 2,328,784 to 2,055,496 B. This is not dashboard or deployed route transfer. Descriptor construction is still O(P); parsing drops authoring documentation bytes. Pure CPU evaluation is unmeasured; corrected timer includes request plus initialization.

4. **Unmount closed board-duplicate forms.** One existing Mantine prop replaces default hidden Activity retention. Formal nine pairs per 1/25/100 boards and create/no-create permissions (108 fresh browsers) pass validation, submit, cancel/reopen reset, transition and permission scenarios. At 100 create-enabled boards, initial GC heap medians 58,231,628 to 52,082,400 B and DOM 4,422 to 2,522; first-open unpaired medians 120.9 to 148.3 ms, but paired difference median -1.9 ms with -64.6 to +56.0 ms range: latency cost is inconclusive. Both variants have zero initial requests. Query caches for visited names remain by their normal five-minute lifetime. Post-navigation baseline hidden DOM is scheduled at React background priority, so the 50 ms DOM snapshots are not a stabilized plateau. Final-stage and variance details are in the measurement report; do not add initial savings to other fixtures or claim deployment-wide savings. Closed-form initial state space changes from O(B*F) mounted form state to O(B) cards, with mount work on opening.

5. **Release expired Custom Widget response values while idle.** One unref'd earliest-expiry timer prunes expired entries without another request. Nine alternating pinned-Node pairs use concurrent batches at 1/25/100 entries with 256 KiB payload strings. At 100 entries, idle post-GC fixture heap medians fall from 42,070,424 to 16,213,736 B; explicit invalidation then frees 26,246,352 B before versus 1,296 B after, supporting retention attribution. Five 25-entry expiry generations plateau before and after: this fixes bounded idle retention, not demonstrated unbounded growth. Capacity (1,000), TTL, epoch invalidation, in-flight coalescing, result ordering and response data remain unchanged. Insert scheduling is O(1); callbacks make two O(C) scans with C bounded at 1,000. Idle process CPU at 100 entries rises from median 1.313 to 7.528 ms, including background runtime work; pure callback CPU is unmeasured. Per-run sampled maximum RSS medians are 215,764,992 to 219,398,144 B with overlapping ranges, not a peak-RSS improvement. Live entries may still retain large values; no byte cap is added. All hit/refetch, refreshed-hit, invalidation-generation and 1,001-entry capacity checks pass.

## Rejected or deferred

- **Assistant module focus-reference cleanup:** archived and reverted. Nine pairs plus neutral-focus follow-up showed equal DOM and no heap benefit despite clearing the stale global reference. Other React/browser retainers remain. No RAM fix is claimed.
- **Notebook on-demand HTML:** not retained. The compatibility smoke produced identical normalized HTML in both fixture variants, but baseline fidelity failed because an initial update apparently normalized content before save. This proves neither a production regression nor a performance benefit. No production notebook edit or formal performance result is retained.
- **Original board-form initial-fetch hypothesis:** disproved by browser measurements (zero requests in both conditions). Keep only separately measured form/DOM state benefit.
- **Original Node25 cache experiment:** invalid attribution/runtime controls; retained only as inconclusive history.
- **Viewport-based board prefetch, group/member summaries, server app projections, connection-map ownership, integration/barrel import changes, feed/Kubernetes/icon buffering, docs SDK/animation loading:** inspect reports for exact call paths and smallest candidates; deployment/contract/lifecycle measurements missing. No implementation or resource saving claimed.
- **Modal-stack retention, ArchiveTeam connection Maps, PostgreSQL max=0, CodeMirror URL cleanup:** caller/reducer/default semantics disproved the suspected unbounded-retention claims. No speculative patch.

The audit has no combined whole-app benchmark, RSS percentage, live deployment journey, container-memory measurement or initial deployed RSC/API/WebSocket transfer total. Runtime observations cover finite cycles and cannot establish indefinite flat memory. Current CI is separate from local checks, and a draft PR is not a release.

No existing user Redis or development server was modified. API, auth, Custom Widgets and Next.js package typechecks pass; auth was repeated after the LDAP helper correction. Changed-source oxlint and oxfmt pass; one pre-existing generator shadow warning remains. Architecture passes for 196 modules and final catalog parity passes for 475 descriptors, 479 resolved names and 4,311 binding cases. No tests were added. Independent reviewers checked the full merge-base diff, callers and evidence, then re-reviewed the LDAP helper correction.
