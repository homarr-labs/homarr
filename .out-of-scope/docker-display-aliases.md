# Docker display aliases

On 2026-10-19, the maintainer rejected a display-only alias or rename option for the Docker containers widget. Keep the existing Docker container names rather than adding separate per-widget alias configuration.

This is a product scope decision. It supersedes the earlier post-release deferral of the alias option in #6930.
