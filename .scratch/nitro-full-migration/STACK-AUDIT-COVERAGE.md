1. Read only the frozen report pairs, at the recorded locations and SHA-256 identities. Never count proposed targets, consumer references, handoff references or exclusion globs as owned files. A17's five `ignoredEvidence` entries and other supplemental ignored-output lists are separate metadata evidence, not primary ownership rows.
2. Construct set unions from expanded filenames, retaining every owning audit for collision detection. Do not sum historical initial/second snapshots, line counts or the reports' unlike “owned,” “physical,” “inspected” and “classified” totals. A09's final 340 explicit rows supersede its initial 306-row observation; its 34 active additions are not a second partition.
3. Observe current names with `git ls-files --cached --others --exclude-standard -z`, plus separate cached/stage/modified-name metadata. Deduplicate NUL-separated names. Use non-following `lstat` only for missing names and link classification; read no product, credential, data, output, installed-dependency or symlink-target contents. At this observation no owned name was missing during `lstat`; `.claude/skills` was the sole symlink and was not traversed. Git names and subsequent stats are not an atomic snapshot.

Exclude path components `node_modules`, `.turbo`, `.next`, `.output`, `.nitro`, `.tanstack`, `dist`, `build`; exclude A08's 14 `generated_result` rows and `tools/motion-reel/reel.js`. Current excluded entries are 451 instruction/scratch/evidence/experiment names, 34 audit outputs, 14 check-result artifacts and 1 bundle. These 500 are never product coverage.

Retain repository-owned inputs needed by the product/support surface—migration SQL/journals/snapshots, locale catalogs, generated component/public schema catalogs, lock/checksum files, static media and dependency patch inputs—but preserve their actual metadata/exclusion status. Retention is not source inspection, artifact freshness, byte/visual review, safety clearance or acceptance. Historical/showreel/developer-tooling inputs are support assets, not runtime product modules. Suspected benchmark-result/input roles remain a boundary ambiguity unless the frozen report establishes provenance.

All 95 currently modified tracked product/support names intersect recorded filenames, but report-only reconciliation cannot establish their contents or whether changes postdate each audit. Existing filename coverage therefore does not certify the current bytes.
7. Hash a path set as SHA-256 of UTF-8 `sorted(exact_paths)` joined by newline with one terminal newline. Hashes are filename-set fingerprints, not product-content hashes.
