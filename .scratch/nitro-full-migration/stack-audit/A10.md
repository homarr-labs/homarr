## Startup, stop and status-delivery registration

1. Backend owner opens/migrates/adopts the main owned resource epoch and actual exclusive runtime admission first; supplies genuine readiness, SQL codecs, effect transports, immutable job names and registered status record keys. Share one status consumer for begin/finish and viewers; same-instance local notification does not deliver another process's writes.
2. Construct factories without starting schedules. `initializeAsync` performs disabled-provider cleanup (source log/continue failure behavior), interrupted status repair, durable configuration read and paused schedule creation. `startAllAsync` applies beforeStart/runOnStart then resumes. Analytics/icons retain Monday/run-on-start restrictions; ping retains minute, pre-start registry clear, URL dedupe and all-settled effects. 3. Genuine authorized same-listener HTTP/SSE registration binds the eight native procedures. Status runtime attaches before snapshots and retains monotonic keyed reconciliation. Neither status wrapper lifetime checks nor client permission props implement security.
4. Stop admissions/timers and abort/drain jobs **while the host status lifetime remains alive**, allowing final idle/error persistence. Await actual `jobs.stopAsync` including controls, reads, manual effects and finish; then dispose streams/status/backing, owned request/statistics/HTTP transports and native resources in the genuine dependency order before SQL/epoch replacement. Status disposal awaits all started reads, registration, sink delivery and unsubscription, preserving original/cleanup failures. Never close SQL because a timeout, base-handler grace or iterator return merely completed logically.

HTTP correction reuse: available unused bodies are cancelled before owned scope abort; owned dispatcher destruction and fetch settlement are awaited; late cancellation suppression requires exact owned reason/dispatcher/fulfilled destruction provenance. Unknown/locked/borrowed cleanup remains quarantined. This audit neither repeats that review nor proves sockets actually retired.
