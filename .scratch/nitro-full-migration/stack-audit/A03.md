## Backend-only structure and browser contracts

Candidate application boundary: `apps/backend/server/{bootstrap,runtime-composition,transports}` owns listener/bootstrap, genuine Auth/SQL/state/trust acquisition, Fetch RPC, REST/OpenAPI, MCP, binary/image/proxy/backup endpoints and request/lifecycle disposal. `apps/nitro` owns React, Query/provider/browser client, Router navigation/loader/prefetch/hydration. Same-listener HTTP/SSE semantics remain required; separation does **not** create a second host or loosen origin/CSRF/private access. App-source composition movement is another scope; no app implementation was read here.

Keep reusable native API domain factories/resources under `packages/api/src/nitro/{routers,resources}` and backup/media runtimes package-owned. Proposed `src/backend/index.ts` may export selected server entrypoints; never make browser exports transitively import it. Proposed `src/contracts/*` contains only source-derived validation, public transport input/output types, metadata and safe domain results; no request, SQL database/table, authority lease, server settings/env, Buffer/crypto/sanitizer or backend factory values. Type-only server inference is useful preparation but does not by itself establish an independently pure browser declaration graph. Contract owner must reconcile canonical whole-router type with all family producers; keep held builders absent.

`src/browser/query.ts` belongs to Query adapter owner, not backend spine. It preserves actual-input identities, invalidation/cancel/set ordering, lifetime retirement, 30-second/metadata staleness policies, forbidden-data eviction, retries and widget exclusions. `query-cache.ts` currently assumes **tRPC-shaped keys** (`queryKey[0]` path array) and **tRPC-shaped errors** (`error.data.code`); migrate to actual oRPC adapter keys/error contract, not tuple casts or renaming `isTrpcForbiddenError`. Router owner—not Query owner—owns route loading/prefetch/navigation. SSR request QueryClient must remain isolated; security authority cannot derive from cached query values.
