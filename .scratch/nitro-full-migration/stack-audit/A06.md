## Query / Router contracts that must precede implementation

1. Publish browser-safe canonical oRPC client/output/input types for every leaf listed in JSON/above. Importing a server factory's **types** is source preparation, not a public runtime contract or mounted endpoint. The new shared adapter must use actual oRPC-generated `queryOptions`, `mutationOptions` and key utilities, one lifetime-owned QueryClient, and real AbortSignals. Do not fabricate a tRPC-shaped `clientApi`, guess key arrays or read backend runtime from the browser.
2. Query key scope includes principal/session revision and exact procedure/input. Successful app writes reconcile app list/selectable/by-ID/catalog consumers; Board writes reconcile named/home/catalog/overview plus affected settings; preferences reconcile `user.getPreferences`, effective SettingsProvider snapshot, default-engine and relevant home-board reads; media requests reconcile all three original targets across Search/widgets. Cancel/fence old reads before publishing saved canonical data, retain reviewed retired-owner invalidation and unknown-outcome behavior. Native authorization/currentness remains server-owned.
3. Preserve recorded explicit policies: Board seed freshness **30 s**; palette catalogs **30 s**/no focus refetch/refresh-on-open; media targets **60 s**; discovery/capability reads **retry false**/no focus refetch; icon and bangs previous-data presentation; existing debounce limits. No assigned source sets explicit `gcTime` or legacy `cacheTime`; inherit a genuine accepted shared policy rather than asserting a made-up lifetime. Source previous-data display is not permission to act on obsolete remote results; keep accepted Search/current-name fences.
4. Router must map source hrefs to registered typed destinations with params/search, preserve raw duplicate unrelated query values and query-only/hash/relative URLs, encode board names exactly once, and retain native external/custom-protocol/new-tab/modifier/ref semantics. Source Link `prefetch` is forwarded only: the actual TanStack **intent/preloadRoute + loader ensureQueryData** join must use the same generated query key and avoid duplicate network reads. Prefetch false disables preload; null/default follows the chosen source-compatible owner policy. Query caching alone is not navigation/prefetch.
5. `router.refresh`/server revalidation become confirmed Query reconciliation **and** Router loader/context invalidation. Refresh success must update source settings/environment/session-dependent rendering while respecting dirty drafts and session generations. Route loading/error/redirect/unload/scroll/focus/before-leave behavior belongs to route/composition owners. Cookie/bootstrap HTTP reads stay server-owned; no `document.cookie` principal/claim extraction.
6. Genuine provider order from the frozen global handoff: settings → session → locale → theme → direction → query → Jotai → modals → notifications → spotlight → assistant, with navigation supplied by the real Router. Exactly one theme/direction owner, modal renderer, notification surface and stable per-app stores. Root handles CSS/font/CSP/lang/dir and matching SSR/client snapshots; do not remount all providers on every locale change or manufacture contexts/principals.
7. This partition owns no direct Redis cache/pub-sub implementation. Suitable bounded non-authoritative backend cached reads may move to Nitro KV under their producer owners; onboarding claims, sessions, permission/current-step decisions and coupled writes cannot become fake KV transactions/CAS. Browser Query state is presentation, not authority; preserve genuine producer-owned invalidation/event delivery rather than inventing subscriptions.

## Critical blockers and exclusive future cuts

These are **proposed nonoverlapping allocations**, not new leases or permission to resume frozen owners. Backend relocation, declaration writes and Q16/Q17/Q18 decisions remain with the coordinator.

- **C1 Query foundation (outside A06):** one owner for canonical browser client/types + oRPC TanStack Query adapter/key/invalidation/lifetime utilities; API authority/atomic/multipart producers remain separate. Resolve it before consumers.
- **C2 Router foundation (outside A06):** one owner for actual app navigation adapter/typed routes/loaders/preload/refresh/dirty-navigation join. It consumes the existing UI adapter without rewriting `packages/ui`.
- **C3 Board package closure:** only `packages/boards/src/context.tsx`, `packages/boards/src/updater.ts`, `packages/boards/src/edit-mode.tsx` and owned local exports, consuming C1/C2; retain pure layout/scale bodies. Whole-board SQL authority is not part of this cut.
- **C4 collection source closure:** only `forms-collection/src/**` and `modals-collection/src/**`, retaining Mantine views and true callback contracts; no shared Query/Router implementation or producer mutation. Icon and multipart holds are explicit prerequisites.
- **C5 palette closure:** only `spotlight/src/**` and owned pure-helper exports, extracting the three exact helper leaves above and closing missing commands/preferences/directory/board/page/Assistant registration. Reuse reviewed Search intent/focus fixes; do not rewrite existing candidate Search feature files in this allocation.
- **C6 onboarding closure:** only `onboarding/src/**` and slim local exports; preserve all source styling/assets/sounds and close held restore/claim/account/complete/key/Assistant joins only after genuine producers exist. Keep account cancellation fix and no-users/current-step transactional holds.
- **C7 shared provider/store closure:** one owner for `modals/src/**`, `notifications/src/**`, `settings/src/**` and genuine application-owned resource contracts, excluding C5's spotlight source. Choose source modal renderer versus accepted bridge explicitly; preserve existing global-tools close-all fix. Shared UI/form source ports are reused; any necessary UI public-export change needs a separately exclusive owner.
- **Composition/manifest/host owner:** publishes declarations and installs the accepted provider/route/client graph only after C1–C7 dependencies freeze. Existing `ui/navigation` export/TanStack Query declaration are already present. HTTP/media/assets, backend boundary, auth issuer/claims and both-engine atomic writes are not UI adapters and cannot be bypassed with held-ready flags.

Evidence is read-only source coverage, not lint/typecheck/runtime/browser/security/native transport acceptance. No tests or checks were run in this audit, and no prior validation result is promoted to current composed acceptance.
