## Hidden definition / option-input closure

Canonical definitions are not uniformly pure metadata. `bookmarks/index.tsx` imports add-button/form/group UI and acquires Apps `byIds` through `useData`; `timetable/index.ts` owns debounced station discovery with actual `baseUrl/itemId/boardId/query`; `docker/index.ts` owns endpoint discovery; `beszel-system-stats/index.ts` owns system choices; `immich/album-carousel/index.ts` owns album choices and 15-minute staleness. Health/System Disks definitions import `storage-volume-options.ts`, whose per-integration `useQueries` preserves scoped values, deduplication and partial-error semantics. Replacing component loaders leaves these edges untouched.

`_inputs/index.ts` eagerly imports every input. `_inputs/form.ts` connects the legacy modal type and real form context. Dynamic select/multiselect and integration select inputs execute definition-provided hooks, retain unavailable saved values, pending/error presentation and limits. Specialized input edges are concrete: location search; Apps selectable/admin create; Anchor note discovery; Umami website/event discovery; Stats catalog-per-integration discovery; Custom Widget available/optionRequest, normalization, workbench editor and icon picker. `_inputs/widget-multiReleasesRepositories-input.tsx` additionally owns `widget.secrets.getConfiguredKinds/setSecret/deleteSecret`, Auth/admin behavior, Docker repository import, modal/notification flow, version-filter parsing and provider icons. These are not covered by on-tile view leases.

`options.ts` is an option builder, **not** a complete parser. Preserve non-enumerable `OPTIONS_SUPER_REFINE`, explicit validators, `multiText` array wrapping, internal values, defaults, timezone/countdown ID constraints and limits, `stats/config.ts` schema, integration min/max and PatchMon cross-field threshold refinement. `modals/widget-edit-modal.tsx:422–458` supplies the real source validation assembly. A default-shaped or pass-through parser cannot replace it, nor may a port silently strengthen validation and lose durable option values.
