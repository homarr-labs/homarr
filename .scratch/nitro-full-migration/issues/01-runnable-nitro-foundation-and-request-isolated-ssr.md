# 01: Runnable Nitro foundation and request-isolated SSR

**What to build:** Cold-load and hydrate a public React route on the sole Nitro v3 application, with typed file routes, nested recovery and a safe request snapshot. Protected slots deny by default while one composer accepts feature contributions. This is the named minimal shared expansion, not full-product authentication or parity.

**Blocked by:** None (can start immediately).

**Status:** accepted — bounded public Bun r2 foundation, Oct 10, 2026. No whole-product or private-runtime acceptance.

- [x] A public route supports cold SSR, reload and client navigation with typed params/search, nested pending/error/not-found/redirect outcomes and correct response status; protected slots reject access without real identity/policy rather than mounting fixture admin.
- [x] Each request owns its Router, QueryClient, principal/setup context, memoization and locale/theme snapshot; serialized bootstrap excludes secrets, claim tokens, repositories and callbacks, and concurrent requests cannot replay one another's private state.
- [x] Settings/session/locale/theme/direction/Query/Jotai/modal/notification/Spotlight/Assistant contribution slots install once in an explicit provider order; unavailable features stay unavailable rather than acquiring permissive substitutes.
- [x] One typed service/contribution mechanism assembles runtime handles, response effects including multiple cookies, abort/readiness/disposal hooks and dispatch precedence for APIs/auth/streams/binary/assets before SSR fallback.
- [x] Query refresh, Router loader refresh, backend render revision and session/resource-policy invalidation remain distinct; identity changes cancel or mask stale private results and recovery reloads authorized data.
- [x] File-route generation follows descriptive folder-local filenames, ignored helpers and root/index/layout/pathless/non-nested/dynamic semantics against the pinned toolchain; future focused SSR isolation, denial and hydration evidence closes this bounded shell without waiting for every feature.
