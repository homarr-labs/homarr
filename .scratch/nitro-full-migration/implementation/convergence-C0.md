## Canonical numeric and adoption requirements

The private string fields are wire representations, **not compile-time proof of validation**. Remaining C validation must check canonical decimal TEXT, at most 19 digits, no sign/space/leading zero/exponent, then checked BigInt within signed64. Head permits `0..9223372036854775807`; credential lifetime/write permit `1..9223372036854775807`, with `lifetime <= write <= head`. SQLite stores INTEGER and rejects non-integer storage classes; PostgreSQL stores BIGINT. Fixed reads CAST sequences AS TEXT; binds use validated canonical decimal strings cast to the engine's integer storage type. Checked increment rejects exhaustion before original DML. Validate canonical lowercase UUIDv4 namespace. No JS-number sequence mapping, guessed inversion, wrap, reset or caller-selected allocation.
