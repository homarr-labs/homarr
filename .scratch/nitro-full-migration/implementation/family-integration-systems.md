- `readAsync` records a discriminated callback outcome, awaits actual `response.body.cancel()` on both callback success/failure and direct redirect responses, and protects cleanup rejection as `response-retirement`. Callback failure plus cancellation failure survive together. Unknown callback failures latch before cleanup begins; cleanup/transport/redirect failures also latch on the shared operation. Subsequent `assertActive`, request entry and optional gates throw that failure instead of issuing fallback/new requests. Already-launched work still awaits its real response/cleanup/compound settlement; no fake destruction, racing timeout or replacement controller was introduced.
- Removed the second generic transport sanitizer at this boundary. Any bound-fetch rejection is a protected `transport` failure, retaining the actual error supplied by the frozen binding and any already-aborted request signal reason. If that producer already sanitized away a redirect cause, it remains unknown and fatal; it is never reclassified as an ordinary optional provider failure.
- Changed only the request redirect mode from `error` to `manual`, with an explicit pre-callback 300–399 check producing `redirect-policy` and retaining the numeric status. No redirect target is followed, used to construct a second request or logged. Cleanup still runs and is awaited; its rejection is protected along with the redirect hold.
- `rethrowCritical` now permits fallback only for actual Zod schema errors or actual `ResponseError` instances with integer 400–599 status. Protected aggregates, unknown transport/operation failures, binding/currentness holds, certificate failures, cancellation and unknown JSON/body-read errors are fatal. Zod membership is by the verified installed constructor, never an error-name/string match. Schema callbacks outside `readAsync` still pass through the same gate.
- `runAsync` still uses the frozen owned-lease helper and awaits its real release. If release rejection replaces a recorded operation failure, both are retained in a protected `lease-retirement` aggregate. The connection-test wrapper likewise records its callback error, waits for the real transport/test release, preserves a distinct later release error and rethrows a protected callback failure even if the frozen testing service converted it into an unknown-error DTO.
