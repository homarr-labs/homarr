## Lifetime and central mount contract

- The host must supply a real session/request-scoped `IdentityClient`, authenticated principal with current expanded grants, opaque `authorityKey`, source demo state, enabled providers and source-derived locally managed providers. Unknown/loading/anonymous authority must use the unavailable branch. Configuration hints are UI hints only; they do not authorize RPC.
- `authorityKey` must change for each replacement authority snapshot, including same-user refresh, logout, expiry, revocation and relevant membership/resource grant changes. Private children remount on that key, principal ID/permissions or provider/demo changes. The boundary owns a separate ephemeral QueryClient; it cancels queries and clears its cache on retirement/unmount. No private result is hydrated from invented initial data or reused from another authority.
- Queries pass their AbortSignal directly to oRPC. Direct mutation promises use component-owned cancellation, synchronous duplicate-submit protection and no automatic retry. Inputs/results are not put in a TanStack mutation cache. API-key/invite plaintext exists only in the mounted component's state and is discarded on dismiss/navigation/authority replacement. Copy is an explicit user action.
- Successful self profile/avatar/preferences/deletion, group membership/deletion/home-default and permission writes retire private children before requesting host authority refresh. Refresh failure leaves an explicit unavailable message; it does not repeat the acknowledged mutation or re-open stale private data. Host refresh must provide a new keyed snapshot before the subtree resumes. Ordinary acknowledged writes invalidate the feature's private query cache.
- The host must mask/retire the mounted feature before an external authority transition, and wire source expiration/revocation/resource-grant refresh. This lane does not implement an auth/session SQL reader, issuer, cookie writer, CSRF/origin transport, cross-tab synchronization or current-authority-to-COMMIT lease. Aborting a request is not proof that a server write did not commit. Ambiguous network outcomes need host/native reconciliation, not an automatic POST retry.
- Native current-authority/writer/lifetime admission and same-listener mount remain unjoined. Nothing here mounts protected procedures or resolves an unknown principal. Supply only admitted native transport and writer bindings after their owners' review. No provider constructor, environment key, real credential, live database or production listener was consumed.
- Mount under the real Mantine theme/direction and source locale context. Text here is English and does not claim a completed standalone-localization or SSR date-formatting join; native dates remain actual returned values, and invitation entry uses the browser's local date/time converted to ISO. Translation/culture formatting, canonical URL routing/deep links and host navigation recovery remain central follow-up work.
- Authentication-peer work owns `/auth/invite/:id` registration consumption, login/logout, callback/error screens, cookie/session establishment and JWT-related decisions. The invitation UI merely formats the existing source invitation URL for delivery; it does not claim the auth route is mounted or create a session. Onboarding initial-user/initial-external-group establishment is excluded.
