## Real effect / transport ownership

Construction starts no provider request, agent, listener, timer, socket or persistent cache. Executable reads enter the supplied frozen `transport.runAsync(context, closure)` and `withIntegrationTestingAsync`; every actual HTTP call uses `lease.input.fetchAsync`, and every actual Jellyfin subrequest uses `lease.input.axiosInstance`. An owned lease is released and awaited in the existing helper's finally; a shared lease remains its physical owner's responsibility. No ambient Core fetch/certificate-agent/Axios constructor, Redis store, logger, env initializer, source class instance or legacy runtime is imported at runtime.

Response callbacks await JSON/text consumption; untouched bodies are cancelled and awaited in finally, including status-only tests and privately retained status-only mutation algorithms. Operation signals compose with the original Jackett timeout; redirects are rejected. SDK calls receive operation signal and `maxRedirects: 0`. The supplied frozen producer remains responsible for currentness, trust material, proxy constraints, deadline cancellation, request/agent physical retirement and late settlement; wrapping a closure is not claimed to redirect unrelated transports.

Compound initial reads and homogeneous library/indexer batches await all settlements before propagating rejection. Request metadata work retains actual source all-settled partial-result behavior and checks cancellation before returning partial data. There is no mutation retry or alternative execution lane after uncertainty. No testing input, DTO, flag or log event grants interaction authority: private mutation/indexer-test entry guards always throw, with no optional override or callback that can turn the gate into authorization.

Runtime logging uses the existing supplied log only. Original info-level request/Plex messages are adapted to debug because the frozen log contract has no info level; sorted-image and page-limit diagnostics retain their metadata without initializing logger state. Failed mutation response text is consumed but is not copied into the thrown error (source echoed the provider body). Navidrome unsuccessful HTTP errors retain status without its private credential query URL. Both Subsonic failure-text paths now expose only the fixed `Subsonic request failed` message: no provider error text, nested provider cause, or credential-bearing provider URL is copied into a thrown Error or the direct `TestConnectionError.UnknownResult` cause, and none is logged. Raw Subsonic text remains internal only for the exact empty-library comparison; numeric codes 40/41 retain the genuine unauthorized 401 result, and other failures retain the genuine unknown TestConnectionError category/object. Jellyfin SDK failures use the existing sanitized transport error conversion, not raw Axios config/headers. This describes the corrected channels, not proof of a global error graph audit; complete legacy decorator/error-handler parity remains a coordinator review obligation.
