The factory checks user identity on snapshot acquisition, admission before queries and after awaited identity/grant reads, before secret decryption, after native-client acquisition, immediately before test invocation and before returning read results. ## Preserved source quirks and explicit adaptation deltas

- `getKinds` and `byIds` remain public, including anonymous fixture access; this is source conservation, not a new public exposure decision.
- `all` returns permission flags. `search` removes grant relations and returns the source integration-row fields, **without adding permission flags**, despite its inherited MCP description mentioning them. No silent shape repair.
- Management lists use direct/global integration grants. Board visibility does not confer management full access. Full permits interact/use and interact permits use exactly as the source policy.
- Detail output exposes public secret fields according to `integrationSecretKindObject[secret.kind].isPublic`; private plaintext/ciphertext never enters that output, and each `updatedAt` remains unchanged. Detail public-secret codec failure still rejects the request rather than inventing a value.
- Stored tests decrypt stored candidates, prefer non-null form values (including source null fallback), choose required alternatives in catalog order, prefer matching form alternatives/nonempty alternative over an available empty one, and append only available optional secrets. Failed candidate decryption logs a safe label and skips that candidate, preserving missing-secret behavior. Testing keeps `externalUrl: null`; it does not substitute an app link or implement generic HTTP requests.
- Safe test results preserve the original success/category discriminated union. Upstream diagnostic message/response/status details are not returned. Additional stale/abort checks may deny an otherwise source-successful call; those are explicit admission fences, not claims that a started upstream effect can be rolled back.
- Source test-helper URL log fields and raw crypto error causes are intentionally omitted from injected logs, keeping the categorized credential-free boundary. Kind/name/secret-kind diagnostic fields remain. No new SSRF/origin restriction, URL normalization or trust relaxation was added.
- Create schema remains HTTP(S)-restricted; update schema retains the broader URL validator and nonempty existing-id shape. `attemptSearchEngineCreation` remains the source required create field but is **not acted on by the original create body**. There is no automatic search-engine creation, no new provider kind and no provider default. Four pending schemas are exported intact, not interpreted as implemented mutations.
- Pending create must preserve `integration-create` and conditional `app-create` gates; optional existing-app linking versus creation; test before saving; original error and returned integration/appId shape. Pending update must retain saved kind, null-secret retention/removal, source encrypted comparison behavior and secret timestamps rather than silently repairing them. Grant replacement must preserve the original empty-array and input semantics while using an accepted coherent atomic plan rather than copying the source's unsafe async SQLite pattern.
