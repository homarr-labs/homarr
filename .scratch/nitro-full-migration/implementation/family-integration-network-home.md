## HTTP ownership and error boundary

Ordinary operations use frozen `transport.runAsync` + `withIntegrationTestingAsync`, which acquires the typed `IntegrationTransportLease`, passes its genuine `IntegrationTestingInput`, and awaits owned `releaseAsync` in `finally`. Each fetch uses that input's fetch/dispatcher and the operation signal; no global fetch, Core HTTP/log singleton, Redis, environment initialization, fabricated agent or imported legacy client is executed.

Response parsing stays inside the lease. Status-only and unconsumed failure bodies are cancelled and awaited before leaving the response callback. If cancellation rejects, a protected AggregateError retains the original callback/hold/cancellation exception when present and the actual body-cleanup exception; a successful callback with failed cleanup also throws an aggregate. A successful cleanup preserves any original callback rejection unchanged. This is not a claim of completed physical retirement on cleanup failure. Fan-outs use `Promise.allSettled` and wait for every response callback before throwing, rather than releasing on the first rejecting sibling. Array/source-order error selection is intentional; no successful partial aggregate is invented. OPNsense's inaccessible streaming candidate also awaits reader cancellation and releases its lock. Existing transport acquisition/late-settlement limitations are not resolved by this bucket.

All bucket fetches now request supported manual/no-follow handling. Status301/302/303/307/308 throws `NetworkHomeCapabilityHeldError("redirect-policy")` before ordinary response consumption, without following Location or dispatching another request; its unconsumed body is still cancelled and awaited. The legacy ordinary HTTP/source Pi-hole probe omitted the redirect option and used default follow behavior; the private UniFi generic-login source explicitly used redirect:error. Neither behavior is claimed equivalent to this bounded manual inspection. No accepted redirect-hop trust, credential-forwarding, origin/currentness or release policy exists here, so redirected behavior remains held rather than guessed from an error string or falsely treated as a v6 fallback.

Testing uses the frozen transport test operation, not mutation authority. The wrapper records callback failures so capability/cancellation/trust/currentness/retirement failures cannot be silently converted to normal testing results by the source `TestConnectionService` wrapper. Recorded failures are inspected before the post-test abort check, and protected aggregates are rethrown before checking signal cancellation, preserving the retained callback and cleanup evidence even when the operation is also aborted. Universally unavailable Pi-hole v6/Technitium/UniFi tests throw their hold before entering that wrapper. Other ordinary direct nonredirect test failures retain source TestingResult helpers.

Original decorators/class error normalization are not installed on these detached candidates; genuine original-class delegation and error-handler normalization remain coordinator work. ResponseError and TokenExpiredError identities are reused. Malformed AdGuard/OPNsense tests deliberately hold instead of constructing a nominal substitute for Common's ParseError. Runtime log metadata replaces ambient logger use; unsafe raw logout body text and full caught-error logging are not emitted. This means logging representation is not claimed byte-identical to legacy logging.
