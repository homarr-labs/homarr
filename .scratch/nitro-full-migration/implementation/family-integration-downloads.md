## Physical ownership and error changes

- Integration input/resources/context are explicit constructor arguments. No ambient Core fetch/certificate-agent creation, logger, Redis, environment, dynamic legacy class import or runtime factory import occurs in these preparations.
- Ordinary queries and Deluge authentication use `transport.runAsync` around `withIntegrationTestingAsync`. Each request actually calls the acquired input.fetchAsync with operation signal and redirect error; this is not a closure fence around legacy I/O. The existing owner supplies trust/proxy/lookup/currentness/cancellation, tracks fetch, and retires the owned dispatcher/agents. The helper awaits owned release even on failure; shared input lifetime is the supplied owner's responsibility.
- Per-kind tests use the genuine frozen transport test callback with its bound input, not a made-up testing principal. Authorization/management binding remains a central hold, including currently refused native class resources for these kinds.
- Bodies are fully awaited before returning; unconsumed status-failure bodies are canceled and cancellation is awaited before release. SAB/NZBGet/Aria2 parallel read branches and the prepared Deluge control fanout use all-settlement, so an early branch failure does not let sibling body work outlive the closure. This intentionally changes Promise.all early-rejection timing, not successful results.
- Source classes in this bucket did not use the shared persistent session store. No new cache is invented; supplied sessions remain unused. SDK internal state is not declared replaced by it. Deluge's ordinary cookie header is returned server-side exactly as source auth, with source redaction values; raw headers/body/credentials are never logged.
- Source HTTP statuses retain numeric diagnostics through public Common ResponseError and frozen transport normalization; source error handlers are consulted in order with first-match behavior. Unknown failure causes/logs are sanitized. Source errors/interfaces/types are imported by pure leaves or type-only, not through legacy class/root barrels.
- Newly decoded NZBGet/Aria2 RPC envelopes explicitly reject malformed/missing result and truthy error with a local protocol error carrying only kind/method/numeric code. Legacy response assertions could instead let undefined escape or fail later. This stricter failure boundary is a recorded change requiring review, not exact legacy malformed-response parity. NZBGet/Aria2 tests also validate their source declared version response shape rather than ignore the result. No raw provider error text is exposed.
- Aria2 HTTP status is checked before JSON decoding through the common request path; its source Proxy decoded JSON first. Mixed unsuccessful-status/invalid-JSON precedence is therefore a recorded difference. Transport redirects are now explicitly refused on all ordinary HTTP paths where the source did not already specify refusal, retaining the frozen trust boundary rather than copying ambient redirect behavior.
- Every supported public mutation remains held even though algorithms are prepared. A testing lease, query context, optional log, callback or item supplied by the caller is not interact authority. There is no automatic retry or false success after uncertain control failure.
