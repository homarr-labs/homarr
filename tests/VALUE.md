# Test value ranking

All 16 declarations, ordered by likely user harm prevented and independent regression signal, then maintenance cost. This is a source review, not measured historical bug yield or a claim of complete coverage. Short names identify declarations in [flows](flows/persisted-management.contract.test.ts), [media](integrations/media.contract.test.ts), and [network](integrations/network.contract.test.ts).

## Removal candidates

- **Rank 16 first:** overlaps rank 15's HTTP/schema classification. Keep while Gluetun's multi-endpoint aggregation is independently implemented; remove if a shared public contract demonstrably covers partial failures.
- **Rank 14 next:** worthwhile only while Basic auth and nullable custom OpenVPN remain supported. Remove with that product support, or when another maintained contract covers both paths.
- **Rank 15 can shrink:** malformed JSON and malformed schema currently protect separate parsing stages. Collapse only if they become one externally indistinguishable path; retain the outage-versus-invalid-data distinction.
- No unconditional deletion is recommended from this replacement suite. Do not add variants solely for assertion counts, functions, or line coverage.

## Limits and upkeep

- Six external services are represented. Most adapters, TLS/certificate handling, rate limiting, reconnects, streaming and provider upgrades remain unverified.
- Fixtures are synthetic protocol examples, not live upstream compatibility proof. Changes require a documented upstream contract or observed failure; never refresh expected outputs merely to accept new production output.
- Router flows exercise real SQLite and Redis but bypass browser, HTTP session establishment and PostgreSQL. They do not prove UI behavior, authentication-provider behavior, migration compatibility across all released databases, or end-to-end service deployment.
- Re-rank when a real regression, obsolete supported behavior, or a shared contract changes a test's value. Keep a case only while its stated failure remains plausible and independently observable.
