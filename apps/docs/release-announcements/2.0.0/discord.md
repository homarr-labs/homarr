# Homarr 2.0.0 — our biggest upgrade yet 🚀

Homarr 2.0 builds on the dashboard and launcher you know. Our biggest upgrade yet helps you **see, find, configure, and act on** more of your self-hosted stack while keeping it familiar.

**What v2 brings**
🤖 Assistant approvals for sensitive actions + auth/permission-bound MCP tools
🧩 Custom Widgets v2: APIs, write actions, buttons/toggles, 15 option controls, diagnostics, and AI authoring
🏪 Community Workshop for Custom Widgets and CSS
🖱️ Rebuilt drag & drop with containers, rails, resize, and Ctrl/Cmd batch moves
📱 One board with automatic Base + Mobile layouts
⌨️ Cmd/Ctrl+K global search, a visual board switcher, and configurable headers
🔭 Advanced focus views across 40 opted-in widget definitions
🌦️ Redesigned Weather/Clock, new Air Quality/Countdown/Timer, and broad widget polish
🧭 A six-stage onboarding studio, service auto-detect, and a polished login experience
🐳 Assisted Docker discovery, multiple Docker/Podman endpoints, `homarr.*` labels, and selected `homepage.*` fallbacks
🔐 A clearer permission matrix, server-side filtering, LDAP first-login provisioning, and configured OIDC/group sync
➕ Contextual Add content and Quick Add flows with fewer detours
🎨 Instance name/logo, colors, corner styles, auth-page branding, and global Custom CSS
⚡ Parallel loading, request deduplication, bounded caches, optional Redis coordination, lazy screens, and isolated previews

Custom Widgets remain **Beta**. Back up Homarr and copy your data volume before upgrading; never test a prerelease against your only production copy.
