Monitor which movies, episodes and books are missing from your library, and track what is currently being downloaded.
The widget combines data from Radarr, Sonarr and Bindery, with separate tabs for missing items and active downloads.

### Tabs

| Tab         | Description                                                                                                            |
| ----------- | ---------------------------------------------------------------------------------------------------------------------- |
| **Missing** | Lists movies (Radarr), episodes (Sonarr) and books (Bindery) that are monitored but not yet available in your library. |
| **Queued**  | Shows items currently being downloaded with a progress bar and estimated time remaining.                               |

### Sizing

The widget adapts to its container size, so it looks good at any grid size:

- **Wide** — fits as many columns of cards as the width allows, filling larger widgets instead of stretching a single column.
- **Short** — packs items into more, tighter columns so they stay visible in the limited height.
- **Narrow (1×N)** — tab labels collapse to counts only and posters scale down.

Each item shows its poster art, a type badge, and — on the queue — an animated progress bar with the estimated time remaining.
