The Media Missing & Queue widget shows monitored movies and episodes that are not yet available and items currently in
the Radarr or Sonarr download queue. Advanced view shows both groups with queue status and time remaining.

### Tabs

| Tab         | Description                                                                                           |
| ----------- | ----------------------------------------------------------------------------------------------------- |
| **Missing** | Lists movies (Radarr) and episodes (Sonarr) that are monitored but not yet available in your library. |
| **Queued**  | Shows items currently being downloaded with a progress bar and estimated time remaining.              |
