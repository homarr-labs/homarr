The Komodo Overview widget shows the number of healthy resources compared with the total number of servers, stacks, and deployments. It also displays a combined problem count for the enabled resource types. Each of these four sections can be enabled or disabled in the widget settings. The summary uses at most two columns to keep its cards readable. When enough vertical space is available, the widget shows a compact list of up to 20 enabled resources that need attention. The problem list remains scrollable without displaying a permanent scrollbar.

The refresh interval can be configured between 1 and 300 seconds. It defaults to 30 seconds.

### Status handling

| Resource       | Healthy   | Warning                                                   | Error                          | Unknown                             |
| -------------- | --------- | --------------------------------------------------------- | ------------------------------ | ----------------------------------- |
| **Server**     | `Ok`      | `Disabled`                                                | `NotOk`                        | Any unrecognized state              |
| **Stack**      | `running` | Transitional, stopped, paused, created, removing, or down | Restarting, dead, or unhealthy | `unknown` or any unrecognized state |
| **Deployment** | `running` | Transitional, paused, exited, created, or not deployed    | Restarting, dead, or unhealthy | `unknown` or any unrecognized state |

Every non-healthy resource contributes to the problem count. Templates are excluded because they are not active resources. Unknown states remain visible as unknown instead of causing the widget to fail.
