A stacked area or bar chart of alerts over time, split by severity, with the total per severity in the legend. The interval is picked automatically for the range unless you choose one.

Wazuh rule levels are grouped into four severities across the Wazuh widgets: **low** (0-6), **medium** (7-11), **high** (12-14) and **critical** (15 and above).

### Requirements

The chart is built from the Wazuh **indexer** (`wazuh-alerts-*`), so the integration needs indexer credentials. See the [Wazuh integration](/docs/integrations/wazuh) for the credential options, certificates and the optional dashboard URL used for links.
