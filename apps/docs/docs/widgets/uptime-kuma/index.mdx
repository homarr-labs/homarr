This widget shows the monitors of an Uptime Kuma status page: the overall status, each monitor's recent heartbeats, its 24-hour uptime and response time, and pinned incidents or active maintenance.

The widget only sees what the status page publishes:

- Only monitors in the status page's groups are shown.
- Certificate expiry is only available when **Show Certificate Expiry** is enabled on the status page.
- The status page does not publish pause state. Monitors with old heartbeats show **No recent data** and are excluded from average uptime.

When multiple Uptime Kuma integrations are selected, monitors from healthy sources remain visible if another source fails. A warning indicator identifies each unavailable integration. If every selected integration fails, the widget reports an error.
