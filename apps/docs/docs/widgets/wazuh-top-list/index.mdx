Ranks alerts by rule, agent, source IP (`data.srcip`), MITRE ATT&CK tactic or MITRE ATT&CK technique, with an inline bar per entry. Rules show their level and ID, and every entry shows how many agents it involves.

Wazuh rule levels are grouped into four severities across the Wazuh widgets: **low** (0-6), **medium** (7-11), **high** (12-14) and **critical** (15 and above).

### Requirements

The ranking is an aggregation on the Wazuh **indexer** (`wazuh-alerts-*`), so the integration needs indexer credentials. See the [Wazuh integration](/docs/integrations/wazuh) for the credential options, certificates and the optional dashboard URL used for links.
