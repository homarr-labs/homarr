The Assistant widget provides the same active conversation as the app-wide Assistant. Messages, tool calls, and
approvals stay synchronized between surfaces.

An administrator must first configure [Assistant](/docs/management/assistant). Short widget layouts show an action to
open the full Assistant instead of compressing the conversation.
