The Media server streams widget combines active sessions from selected servers. It shows playback progress, resolution,
bitrate, location, and direct-play or transcoding state according to the widget configuration. Advanced view adds search,
sorting, and session metadata.

Healthy integrations remain available when another source fails. Navidrome and Plex return currently playing sessions
rather than every connected session.
