The releases widget tracks the latest release of repositories and container images, and lets you read their changelogs.
Releases published within the highlight period are listed under New until you mark them as viewed. Repositories that could not be checked are grouped by cause under Needs attention.
It also supports importing releases from your local docker containers.

### Supported Providers

GitHub, Docker Hub, GitLab, NPM, Codeberg, GitHub Container Registry, Quay, and LinuxServer.io are configured per repository in the widget.
Adding or removing a provider token refreshes active release results.

Each repository is checked at most every 6 hours, so a new release can take up to 6 hours to appear. If a check fails, the last release found stays visible for up to a day.

GitHub allows 60 requests per hour without a token, shared by every repository on the server. If GitHub repositories show "Rate limited by GitHub", add a GitHub token in the widget settings.

For container images tracked by a floating tag such as `latest`, the widget shows the version tag that points to the same image.

For GitHub repositories with more than 1,000 releases, Homarr uses the releases returned before GitHub's history limit. The latest release remains available in the widget.

For GitHub Container Registry, use `owner/package` identifiers such as `homarr-labs/homarr`.
Full image references such as `ghcr.io/homarr-labs/homarr:latest` are also accepted.

### Linking integrations

Linked integrations show the version each service is running next to the latest release. The status compares against the latest release the repository shows, which can be a pre-release, and is unknown when either version isn't a plain version number such as `4.0.20` or `v4.0.20` (LinuxServer.io's `-ls` build suffix is also supported).

<Alert type="note">

The version filter is used to match the version tag of the release. It is a combination of the prefix, precision and suffix.

Setting the Prefix to `v`, precision to `2` and the Suffix to `-alpha`, will match `v1.0-alpha` but not `v1.0-beta`.  
Setting the Prefix to `v`, precision to `3`, will match `v5.2.0` but not `v1.0.2-alpha` or `Beta v5.2.1`.

</Alert>
