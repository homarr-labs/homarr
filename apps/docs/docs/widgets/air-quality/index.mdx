European or US AQI scale; automatic mode uses the US scale for US locales and the European scale elsewhere.

### Data source

Data comes from the Open-Meteo Air Quality API and refreshes every 15 minutes. A recent successful response can remain
visible for up to 24 hours when the API is unavailable.

Set `NO_EXTERNAL_CONNECTION=true` to disable this and other internet-backed requests. If you need to allowlist the
service, use `https://air-quality-api.open-meteo.com`.
