The Entity State widget shows a Home Assistant or Homey entity's state and can optionally toggle it. Advanced view includes the
entity ID, unit, device class, icon, and update timestamps; arbitrary attributes are not exposed.

### Interactions

- Toggle entity state by clicking on the entity (only when clickable enabled).
- After a successful toggle, the displayed state refreshes immediately.
- If Homarr cannot refresh an entity, the last known state stays visible but toggling is disabled until the connection recovers.

### Entity ID

Home Assistant uses native IDs such as `sensor.living_room_temperature`. Homey devices and individual sensor capabilities are mapped to entities by Homarr. Both are available in the searchable entity list after selecting an integration; existing saved IDs remain valid.
