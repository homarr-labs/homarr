The Entity State widget shows a Home Assistant entity's state and can optionally toggle it. Advanced view includes the
entity ID, unit, device class, icon, and update timestamps; arbitrary attributes are not exposed.

### Interactions

- Toggle entity state by clicking on the entity (only when clickable enabled).
- If Homarr cannot refresh an entity, the last known state stays visible but toggling is disabled until the connection recovers.
