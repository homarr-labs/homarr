The Timer / Pomodoro widget runs in the browser without an integration. Timer mode uses one duration; Pomodoro mode
alternates configurable focus, short-break, and long-break phases.

Progress and alert preferences are stored per board and widget in the current browser. Notifications can fire only
while Homarr is open.
