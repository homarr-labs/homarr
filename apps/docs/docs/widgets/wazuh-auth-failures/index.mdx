Totals for failed logins, brute-force alerts and distinct source IPs, followed by the agents with the most failures. Each agent row has a sparkline, the top source IPs, its failed-login total and its brute-force count.

Failed logins are alerts in the `authentication_failed`, `authentication_failures` or `invalid_login` rule groups or with MITRE ATT&CK technique T1110. Brute force covers `authentication_failures` and T1110.

Wazuh rule levels are grouped into four severities across the Wazuh widgets: **low** (0-6), **medium** (7-11), **high** (12-14) and **critical** (15 and above).

### Requirements

The data comes from the Wazuh **indexer** (`wazuh-alerts-*`), so the integration needs indexer credentials. See the [Wazuh integration](/docs/integrations/wazuh) for the credential options, certificates and the optional dashboard URL used for links.
