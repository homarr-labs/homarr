Shows the status and amount of players on a Minecraft server. Compact mode keeps the server icon and player count visible instead of hiding them based on tile size. It supports both Java and Bedrock editions, but only public servers accessible through the [mcsrvstat.us API](https://api.mcsrvstat.us) are supported.

### Data source

We use the Minecraft Server Status API to fetch the server status.
If you need to whitelist the API, use the following URL: `https://api.mcsrvstat.us`.
