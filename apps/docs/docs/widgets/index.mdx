Widgets turn apps, integrations, and Homarr data into useful board content. Some work on their own; others require one or more configured integrations.

Each widget guide explains its configuration, required integrations, supported interactions, permissions, and important empty or error states.

## Add a widget

1. Open a board and enter edit mode.
2. Select **Add item**, then choose **Widget**.
3. Pick a widget and complete its configuration.
4. Move or resize it, then leave edit mode to use it.
