The App widget opens an application or website and can show whether Homarr can reach it. Configure the target and status
check from the tile's edit actions. In view mode, right-click uses the browser's link menu; Homarr's widget menu remains available in edit mode.

In **New window** mode, only HTTP(S) and relative links request a separate browser window. Other protocols, such as
`microsoft-edge:`, `vscode:`, or `ftp:`, are handled from the current tab without requesting an intermediate window.
The browser may still ask for confirmation before opening an associated application.
