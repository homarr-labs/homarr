This widget displays your Beszel alert configurations separated by status (triggered and ok). It also shows alert history with timestamps. Alerts are updated in real time via WebSocket subscriptions.

### Supported Integrations

<WidgetIntegrations
  items={[
    {
      integration: beszelIntegration,
      note: "Displays alert configurations and trigger history",
    },
  ]}
/>

In advanced view, the widget always shows triggered and OK alerts, their descriptions, integration source names, and the complete fetched history. Advanced view requests history even when compact history is disabled and raises the bounded per-integration history request to at least 50 entries, without exceeding 100.
