This widget shows two stats from your WUD instance: the total number of monitored containers, and how many of them currently have an image update available. Optionally, it can also list each outdated container with its current and new version, linking to the release notes when WUD provides one.

### Supported Integrations

<WidgetIntegrations
  items={[
    {
      integration: wudIntegration,
      note: "Displays monitored container and available-update counts",
    },
  ]}
/>

<WidgetInteractionGuide />

In advanced view, the widget always shows its title, update ring, monitored-container summary, and the full list of available container updates. The configured horizontal or vertical layout still applies. Visibility options only affect the compact board view. A failed refresh keeps the last WUD snapshot visible with a stale-data warning.
