The PatchMon widget shows host compliance, available updates, security updates, outdated packages, and optional operating
system distribution. Thresholds can use counts or percentages. Advanced view shows the complete posture summary.

## Authentication

PatchMon data requires a signed-in Homarr session, including on public boards. Visibility options change presentation,
not the integration response available to an authorized user.
