The Komodo Servers widget shows all active servers in a responsive overview. Wide widgets use a table, while narrow widgets switch to server cards. CPU, memory, disk, load average, network traffic, and Periphery version columns can be enabled or disabled independently.

Servers without current statistics remain visible with their Komodo status. Resource templates are excluded. The refresh interval can be configured between 1 and 300 seconds and defaults to 30 seconds.
