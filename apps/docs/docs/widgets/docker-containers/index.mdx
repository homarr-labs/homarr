### Container filters

Filters match complete container names and are case sensitive by default. Matching containers are excluded
unless **Filter as a whitelist** is enabled. An empty filter shows all containers in either mode.

Enable **Allow wildcards** to use `*` for zero or more characters: `qbit*` matches `qbittorrent`, and
`*arr` matches names ending in `arr`. The entire name must still match. All other characters, including
`%` and regex symbols, are literal. Disable **Case sensitive** to match `Qbittorrent` with `qbittorrent`.

### Interactions

Column order and width are saved per widget. These controls are unavailable while the board is in edit mode.

Each container row has an action menu, accessible via the three-dot icon or by right-clicking the row, with the following options:

- **View logs** - opens a dedicated terminal page streaming the container's logs
- **Start** / **Stop** / **Restart** - manage the container's state
- **Remove** - permanently remove the container after a second confirmation click
- **Add to Homarr** - create a bookmark app from the container
