This widget displays containers from Homarr's direct Docker connection or from a selected Komodo integration. Komodo can also add compact infrastructure summary information and a server statistics view.

:::info
Direct Docker access and container actions require administrator privileges. Komodo is a read-only data source and uses the selected integration's permissions.
:::

### Interactions

Hover a column header to reveal its grab handle, then drag it to reorder the table or drag the header's edge to resize it. The layout is saved automatically for each widget instance and restored after a reload. These controls are disabled while the board is in edit mode.

For the direct Docker data source, each container row has an action menu, accessible via the three-dot icon or by right-clicking the row, with the following options:

- **View logs** - opens a dedicated terminal page streaming the container's logs
- **Start** / **Stop** / **Restart** - manage the container's state
- **Remove** - permanently remove the container after a second confirmation click
- **Add to Homarr** - create a bookmark app from the container

These actions are only available with the direct Docker data source. Komodo containers are currently read-only.

When a Komodo integration is selected, the widget can additionally show server, stack, deployment, and problem counts above the main view. The **Servers** view displays CPU, memory, disk, load average, network traffic, and Periphery version data.
