The Countdowns widget tracks up to 20 one-time or yearly events without an integration. Events use an IANA timezone and
can be reordered; the first event is shown in compact view.

Optional progress uses the configured start date. Browser notifications are local to the current browser and can fire
only while Homarr is open.
