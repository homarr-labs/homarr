The DNS Hole Summary widget combines total queries, blocked queries, and blocklist size from selected DNS services.
Healthy sources remain visible when another integration fails.

On an uncached board load, Homarr starts summaries on the server for the initial layout, outside collapsed sections.
Each result appears when ready; integration permissions still apply.

### Configuration

Enable **Use Pi-Hole colors** to color the four statistics red, yellow, cyan, and green with any supported DNS integration. Disable it to use the board's primary color. Both modes respect the board opacity.

Compact cards, including 1×1 widgets on scaled boards, show abbreviated values without icons or labels. Hover or focus a value to see its metric label; larger cards keep their icons and labels.
