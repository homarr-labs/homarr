Counts of vulnerability findings by severity with a distribution bar, the top CVEs (ID, affected packages, score and number of affected agents) and the agents with the most critical and high findings.

Wazuh rule levels are grouped into four severities across the Wazuh widgets: **low** (0-6), **medium** (7-11), **high** (12-14) and **critical** (15 and above).

### Requirements

Findings come from the `wazuh-states-vulnerabilities-*` index on the Wazuh **indexer** (Wazuh 4.8 and later), which needs vulnerability detection enabled on the Wazuh manager. The integration needs indexer credentials. See the [Wazuh integration](/docs/integrations/wazuh) for the credential options, certificates and the optional dashboard URL used for links.
