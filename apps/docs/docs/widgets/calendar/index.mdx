The Calendar widget combines events and upcoming media releases. Healthy integrations remain visible when another
source fails.

View choices are remembered per widget in this browser, including on read-only boards. They do not change the
configured default or other users' views. Set the shared default in the widget configuration.
Advanced view starts in Agenda and remembers its own browser-local selection. Timed events without an end time
occupy a 30-minute slot in Day and Week; their details keep the original event time.

### Interactions

- Hover or select a marked date to inspect its events.
- Month overflow counts open the complete list of events for that date.
