The Calendar widget combines events and upcoming media releases. Healthy integrations remain visible when another
source fails.

Changing the view saves it for the widget across browsers and devices. This requires Change access to the board.
Advanced view enlarges the selected mode. Timed events without an end time occupy a 30-minute slot in Day and Week;
their details keep the original event time.
