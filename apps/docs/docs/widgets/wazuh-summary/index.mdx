A donut of the alerts in the selected period split by severity, with the total in the middle. Each severity shows its count and the change against the previous period of the same length (for example the 24 hours before the last 24 hours). The footer shows the previous total, the highest rule level seen and the indexer cluster health.

Wazuh rule levels are grouped into four severities across the Wazuh widgets: **low** (0-6), **medium** (7-11), **high** (12-14) and **critical** (15 and above).

### Requirements

The severity counts come from the Wazuh **indexer** (`wazuh-alerts-*`). With server API credentials only, the widget shows the manager version and asks for indexer credentials. See the [Wazuh integration](/docs/integrations/wazuh) for the credential options, certificates and the optional dashboard URL used for links.
