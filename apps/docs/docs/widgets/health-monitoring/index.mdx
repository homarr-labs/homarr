Select a server or NAS integration to see its latest readings. Add more integrations to compare hosts. Each host shows the metrics its integration reports. Proxmox has a separate cluster view for nodes, VMs, containers, and storage.

Open a host for its individual readings, or use **Advanced view** from the widget menu to compare systems. System history builds from readings the widget receives while the board is open. Choose a history window longer than the refresh interval so it can contain at least two readings. Reloading the page starts a new history. Gaps indicate missing readings.

### Configuration

Set shared defaults in the widget configuration and save the board. Changes made while inspecting readings apply to the current view.

A custom metric order selects which readings appear first when space is tight. Leave the list empty to use the automatic order and the widget’s existing metric switches.

**Needs attention** includes unavailable or stale systems, reported storage faults, pending updates or reboots, and CPU, memory, or volume usage at or above the configured threshold. Each usage threshold defaults to 90%. A healthy disk can still trigger a capacity warning. On Synology and OpenMediaVault, selecting volumes limits storage warnings to those volumes.
