Counts of added, modified and deleted files, followed by the most recent file integrity monitoring (syscheck) events with the path, the event, the agent and, when reported, the user.

Wazuh rule levels are grouped into four severities across the Wazuh widgets: **low** (0-6), **medium** (7-11), **high** (12-14) and **critical** (15 and above).

/>

### Requirements

Events are syscheck alerts from the Wazuh **indexer** (`wazuh-alerts-*`), so the integration needs indexer credentials. See the [Wazuh integration](/docs/integrations/wazuh) for the credential options, certificates and the optional dashboard URL used for links.
