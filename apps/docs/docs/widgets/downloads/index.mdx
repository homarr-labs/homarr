### Features

- **Responsive table** — columns automatically adapt to widget width, hiding less important columns at smaller sizes
- **Sortable columns** — click any column header to sort ascending/descending
- **Column customization** — choose which columns to display, then hover a header to reveal its grab handle for reordering or drag its edge to resize it; layouts save automatically per widget
- **Right-click context menu** — pause, resume, delete downloads, or copy download names directly from the context menu when the selected integration grants interact access
- **Row expansion** — click any row to see full details inline without opening a separate modal
- **Hover tooltips** — hover a download name to see size, speeds, ETA, ratio, and category; open tooltips close when switching between compact and advanced mode
- **Global stats bar** — show a summary bar with queue progress, total size, speeds, ratio, and per-state counts in compact mode; advanced view always includes it
- **Client filtering** — filter downloads by integration or status using the footer filter panel
- **Global controls** — pause/resume all downloads across all clients from the footer bar
- **Status indicators** — color-coded badges show download state at a glance
- **Speed overview** — total download and upload speeds displayed in the footer

:::note

Compact layouts hide secondary columns as width decreases and can hide the footer on very short tiles. Downloads supports
Advanced view, which restores the denser table, stats, filters, and footer controls in a focused panel.

Pause, resume, delete, and global controls depend on integration permissions. `slskd` does not implement pause, resume,
or delete operations; if shared permission UI exposes those controls, they have no effect for that client.
The screenshot above is a download-row menu, separate from the shared widget context menu described in the board guide.

:::

### Interactions

- **Right-click** any download to open a context menu with the actions allowed by that integration
- **Click** any row to expand it and see full download details inline
- **Hover** a download name for a quick stats tooltip
- **Stats toggle** — show or hide the global stats bar in compact mode; advanced view always shows the stats bar
- **Pause / Resume** all downloads using the footer controls
- **Filter** by integration or status using the filter button in the footer
- **Sort** by clicking column headers; the direction applies to the current view
