The Download Client widget combines active jobs from supported Torrent, Usenet, and other download clients. Rows can be
sorted, filtered, expanded, and configured by column. Advanced view adds queue statistics and the complete selected
column set.

Pause, resume, and delete actions require Interact access to the source integration. `slskd` is list-only. If one source
fails, jobs from healthy integrations remain available.

### Interactions

- Select a row to expand its details.
- Right-click a row to copy identifiers or run permitted actions.
- Use the footer to filter clients and states, show statistics, or pause and resume actionable queues.
