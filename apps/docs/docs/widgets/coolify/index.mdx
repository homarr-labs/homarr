The Coolify widget highlights servers, applications, and services that need attention. The compact view shows status
counts and the most urgent resources without a long list.

Advanced view has an overview and searchable tabs for servers, applications, and services. It shows project and
environment context, links, reachability fields, and nested service applications. IP addresses remain masked until
revealed. Healthy integrations remain visible when another source fails.

### Sections

| Section          | Description                                                                                                                        |
| ---------------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| **Servers**      | Lists Coolify servers, reachability status, and application/service counts per server.                                             |
| **Applications** | Lists applications with runtime status, project and environment context, public URL links, Coolify dashboard links, and log links. |
| **Services**     | Lists services with runtime status, project and environment context, public URL links, Coolify dashboard links, and log links.     |

The Coolify API token is team-scoped; Homarr shows only resources available to that team.
