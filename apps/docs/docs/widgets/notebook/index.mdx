The Notebook widget stores rich text on a board. Its editor supports headings, formatting, lists, links, images, tables,
text direction, and alignment.

Select the edit action or double-click the document to edit it. Save or cancel from the same action area. Editing follows
the board's permissions.

The toolbar includes collapsible sections and table controls for inserting tables, coloring selected cells, editing rows
and columns, toggling headers, and merging or splitting cells.
