Docker Compose is the best starting point for most self-hosters. Choose a platform-specific guide when Homarr will run inside an existing server manager or managed service.

<Callout type="idea" title="Not sure which guide to choose?">
  Start with **Docker Compose**. It is the recommended path, has the broadest community support, and makes updates and
  backups straightforward.
</Callout>
