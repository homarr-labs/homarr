# Runtipi

Homarr is available in the default [Runtipi](https://runtipi.io) app store.

## Installation

Install **Homarr** from the Runtipi app store and select either a port or domain for access.

Runtipi manages start, stop, update, backup, and log operations under **My apps → Homarr**. Use a
[user-config](https://runtipi.io/docs/guides/customize-app-config) to override the generated Compose configuration.

See the [Runtipi installation documentation](https://runtipi.io/docs/getting-started/installation) for host setup.
