Homarr requires:

- `linux/amd64` or `linux/arm64`;
- 500 MB RAM;
- 600 MB free disk space for the container image;
- a persistent writable `/appdata` directory.

`linux/arm/v7` is not supported.

Continue with an [installation method](/docs/category/installation-1). Docker Compose is the recommended general-purpose
deployment.
