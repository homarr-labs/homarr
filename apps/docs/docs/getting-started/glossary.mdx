# Glossary

This glossary explains Homarr's main components and the terms used for them.

| Term                                                      | Definition                                                                       |
| --------------------------------------------------------- | -------------------------------------------------------------------------------- |
| [App](/docs/management/apps)                              | A saved shortcut with a name, destination, icon, and optional status check       |
| [Assistant](/docs/management/assistant)                   | A conversation interface that can use model responses and Homarr tools           |
| [Board](/docs/management/boards)                          | A dashboard page where apps, widgets, and Containers are arranged                |
| [Container](/docs/management/boards#containers-and-rails) | A resizable board area containing apps, widgets, or nested Containers            |
| [Custom Widget](/docs/management/custom-widgets)          | A validated definition for an API-backed board tile                              |
| [Edit mode](/docs/management/boards#edit-a-board)         | The board state used to add, move, resize, configure, or remove content          |
| [Homarr provider](/docs/workshop/homarr-provider)         | An Assistant provider routed through Workshop with a per-user allowance          |
| [Integration](/docs/management/integrations)              | A server-side connection from Homarr to a supported service                      |
| [Layout](/docs/management/boards#responsive-layouts)      | An arrangement of board items selected for a viewport width                      |
| [Provider](/docs/management/assistant#configuration)      | The model API selected for Assistant                                             |
| [Rail](/docs/management/boards#containers-and-rails)      | A fixed area at the left or right of a non-Mobile board layout                   |
| [Task](/docs/management/tasks)                            | A background workload that runs without an active browser session                |
| [Widget](/docs/widgets)                                   | A board tile that displays information or provides actions                       |
| [Workshop](/docs/workshop)                                | A separate community service for sharing Custom Widget definitions and board CSS |
