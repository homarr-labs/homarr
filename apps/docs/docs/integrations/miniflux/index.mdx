### Widgets & Capabilities

The [Stats widget](/docs/widgets/stats) displays the total read and unread entry counts from Miniflux. Create an API key in Miniflux and add it as the integration's `apiKey`; the key must belong to a user who can access the feeds whose counters should be shown.
