### Widgets & Capabilities

The [Stats widget](/docs/widgets/stats) reads Gatus' endpoint status API and displays the number of endpoints currently up, down, unknown, and the total number of endpoints. It uses each endpoint's latest result; endpoints without a result are counted as unknown.
