### Widgets & Capabilities

<IntegrationCapabilites items={[{ widget: statsWidget }]} />

The [Stats widget](/docs/widgets/stats) displays recipes and users in the API key's household, plus the group's shared categories and tags.

<Alert type="note">
  The Stats widget uses Mealie's v2 endpoint, <code>/api/households/statistics</code>. Mealie v1 instances that only
  expose <code>/api/groups/statistics</code> are not supported.
</Alert>
