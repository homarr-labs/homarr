### Storage volume selection

Health Monitoring and System Disks widgets can filter OpenMediaVault storage volumes when **every** selected integration is OpenMediaVault or Synology. Leave **Visible storage volumes** empty to show all volumes, or select the volumes to display. When multiple integrations are connected, volumes are labeled with the integration name.

<Alert type="note" title="Supported integrations only">
  The volume filter is hidden when the widget also uses an unsupported integration such as TrueNAS or Unraid.
</Alert>
