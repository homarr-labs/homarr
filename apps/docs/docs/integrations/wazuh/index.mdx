Wazuh stores data in two places, and each uses its own users:

- The **server API** (default port `55000`) answers agent status and manager version.
- The **indexer** (OpenSearch, default port `9200`) holds alerts (`wazuh-alerts-*`), agent snapshots (`wazuh-monitoring-*`) and vulnerabilities (`wazuh-states-vulnerabilities-*`).

Alerts and severity counts need the indexer. Without server API credentials, agent counts come from the latest `wazuh-monitoring-*` snapshot, which the Wazuh dashboard writes every 15 minutes.

### Adding the integration

<AddingIntegration />

Pick the credential option that matches what you can reach:

| Option                              | URL field                              | Widgets                                       |
| ----------------------------------- | -------------------------------------- | --------------------------------------------- |
| Username & Password                 | Server API, e.g. `https://wazuh:55000` | Agents, alert severity (manager version only) |
| Username & Password & Indexer …     | Server API, indexer URL as a secret    | All                                           |
| Indexer username & Indexer password | Indexer, e.g. `https://wazuh:9200`     | All (agents from snapshots)                   |

### Dashboard URL (optional)

Enter the URL of your Wazuh dashboard, for example `https://wazuh.example.com`, in the optional **Dashboard URL** field. The widgets and notifications then link into the dashboard: events filtered by query, agent and time range, agent pages, vulnerability detection, file integrity and MITRE ATT&CK. Without it, the widgets use the URL of the linked app when that differs from the integration URL.

### Certificates

Wazuh ships with self-signed certificates, and the server API and the indexer use different ones:

- The **server API** certificate (port `55000`) is self-signed. **Test connection** offers to trust it.
- The **indexer** certificate (port `9200`) is signed by the Wazuh root CA (`/etc/wazuh-indexer/certs/root-ca.pem` on the indexer host). When the indexer URL is set, test connection checks it after the server API and shows the indexer certificate. Because it is not self-signed, upload the root CA from that dialog or under **Management → Tools → Certificates**.

Both URLs use the trusted certificates for every request, so nothing needs restarting after a certificate is added. The host in each URL must be a name or IP address listed in the certificate (the default indexer certificate covers `wazuh-indexer` and the addresses given at install). Otherwise the widgets report that the certificate does not match the URL; reissue the certificate or trust the hostname from the test connection dialog.

### Notes

- A default all-in-one install binds the indexer to `127.0.0.1`. Set `network.host` in `/etc/wazuh-indexer/opensearch.yml` if Homarr runs on another host.
