### Widgets & Capabilities

<IntegrationCapabilites items={[{ widget: statsWidget }]} />

The [Stats widget](/docs/widgets/stats) reads Unmanic's worker status with `GET /unmanic/api/v2/workers/status` and pending task count with the read-only `POST /unmanic/api/v2/pending/tasks` endpoint.

Unmanic does not authenticate these API requests. Protect the service with your network access controls before exposing it beyond a trusted network.
