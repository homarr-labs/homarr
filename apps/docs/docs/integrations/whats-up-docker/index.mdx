The What's Up Docker integration lets Homarr connect to your [WUD](https://github.com/getwud/wud) instance so you can see how many of your watched containers have image updates available directly from your dashboard.

### Secrets

WUD 9 requires authentication. The recommended option is a Personal API Token: in WUD, open **My Profile → Personal API Tokens**, create a token with the **read** scope, and enter it in Homarr. This also works when WUD uses OIDC and has no local password. Homarr sends the token as `Authorization: Bearer wud_...`.

Username and password (HTTP Basic) remain supported for existing setups and older versions. WUD versions without authentication can leave the secrets empty.

Credentials are sent to the configured URL over HTTP or HTTPS. Use HTTPS outside a trusted internal network.
