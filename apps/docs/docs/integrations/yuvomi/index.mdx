### Widgets & Capabilities

<IntegrationCapabilites items={[{ widget: statsWidget }]} />

The [Stats widget](/docs/widgets/stats) displays open tasks, open tasks with high or urgent priority, and unchecked
items across all shopping lists. Tasks are counted as the token's user sees them; subtasks and archived tasks are not
counted.

To show Yuvomi events in the Calendar widget, add an [iCal](/docs/integrations/ical) integration with the calendar feed
URL from Yuvomi's **Settings → Feed subscriptions**.
