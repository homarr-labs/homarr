### Trusted widget packages

The [Sonarr operations reference package](/docs/management/custom-widgets/trusted-packages) can combine two Sonarr
integrations, display upcoming and missing episodes and queue progress, and submit a confirmed search for a missing
episode. Search actions use the existing integration API key on Homarr's server and require interaction access.
A successful command submission means Sonarr queued the search, not that it found or downloaded a release.
