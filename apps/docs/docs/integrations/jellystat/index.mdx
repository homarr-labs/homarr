### Widgets & Capabilities

<IntegrationCapabilites items={[{ widget: statsWidget }]} />

The [Stats widget](/docs/widgets/stats) reads Jellystat's `stats/getViewsByLibraryType` endpoint for the last 30 days and displays audio, movie, series, and other play counts. These are playback views, not library inventory totals.
