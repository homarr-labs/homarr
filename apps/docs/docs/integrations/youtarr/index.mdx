### Widgets & Capabilities

<IntegrationCapabilites items={[{ widget: statsWidget }]} />

The [Stats widget](/docs/widgets/stats) displays subscribed channels, downloaded videos and the storage they use, the
downloaded and failed counts of the last run, and the Youtarr and yt-dlp versions. The last-run values come from the
most recent run that downloaded or failed a video, so a later check that finds nothing new leaves them unchanged. They
are empty until such a run has finished.

Requires Youtarr 1.94.0 or newer.
