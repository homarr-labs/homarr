Thingport provides library totals, lists of your recently added, most viewed and most printed models, a featured model of the day and your activity history. Use the URL of the Thingport web interface, not the backend container.

### Integration search

The integration search API supports models, collections and tags. Thingport can be selected as an integration search engine, but Spotlight currently does not display its results.

The API token is read-only and shows the library of the user who created it. The [Statistics widget](/docs/widgets/stats) can also combine Thingport totals with other sources.
