### Searching Thingport from Spotlight

To search your library from Spotlight, go to **Manage → Search engines**, create a search engine, choose **From integration** in the configuration section and select your Thingport integration. Use a short name such as `tport`: shorter ones like `tp` or `tpo` are already DuckDuckGo bangs and appear above it in Spotlight.
