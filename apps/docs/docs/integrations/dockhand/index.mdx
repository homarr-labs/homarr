The Dockhand integration connects Homarr to [Dockhand](https://dockhand.pro) 1.0.25 or newer. Earlier versions have no
API tokens.

### Widgets & Capabilities

<IntegrationCapabilites items={[{ widget: statsWidget }, { widget: notificationsWidget }]} />

- The [Stats widget](/docs/widgets/stats) shows containers (running, stopped, unhealthy, total), available updates,
  stacks, images, image disk usage, volumes and online environments. Totals cover every environment the token can see
  that is currently reachable; offline environments are counted only in **Environments**.
- The [Notifications widget](/docs/widgets/notifications) lists the 50 most recent container events from Dockhand's
  activity log. Dockhand only records events for environments with **Collect activity** enabled.

Two [Custom Widgets](/docs/management/custom-widgets) cover a single environment each. Import a definition below,
select your Dockhand integration as the source, then choose the environment in the widget options. Users need full
access to the Dockhand integration in Homarr to use either widget, in addition to the token permissions below.

- **Dockhand Containers** lists the containers with their state. It can start stopped containers, restart or stop
  running ones, and resume or stop paused ones. Actions ask for confirmation and require permission to modify the
  board item.
- **Dockhand Updates** lists containers with a pending image update. Containers appear only after Dockhand has checked
  them for updates. Newer version tags need Dockhand 1.0.43 or newer, minimum release age holds need 1.0.52 or newer,
  and moved pinned digests need 1.0.54 or newer.

### Adding the integration

<AddingIntegration />

Use the URL of the Dockhand web interface without a path, for example `http://dockhand.local:3000`.

The token's user needs permission to view environments, containers and activity. The Containers Custom Widget also
needs permission to start, stop, restart and unpause containers.

### Troubleshooting

- **401 Unauthorized:** the token is missing, expired or deleted, or Dockhand authentication is enabled and no token was
  entered. Create a new token and update the integration.
- **403 Forbidden:** the token's user lacks a required permission or, with Dockhand Enterprise roles, access to the
  environment.
- **Stats show "—":** no environment is reachable from Dockhand. Check the environment connection in Dockhand.
- **No notifications:** turn on **Collect activity** for the environment in Dockhand.
