### Widgets & Capabilities

<IntegrationCapabilites items={[{ widget: statsWidget }]} />

The [Stats widget](/docs/widgets/stats) reads Homebox's `/api/v1/groups/statistics` endpoint and displays items, locations, labels, items with a warranty, total value, and users. The `/api/v1/groups` response supplies the currency shown with the total value.

### Adding the integration

The default Homebox port is `7745`.

<AddingIntegration />

### Secrets

Homebox requires the username (email address) and password of a Homebox account. Homarr authenticates for each stats fetch and does not retain the session token between fetches.
