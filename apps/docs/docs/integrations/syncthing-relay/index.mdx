### Widgets & Capabilities

<IntegrationCapabilites items={[{ widget: statsWidget }]} />

The [Stats widget](/docs/widgets/stats) reads the relay server's `/status` endpoint and displays active sessions, connections, and bytes proxied.

### Adding the integration

<AddingIntegration />

Point the integration at the Syncthing Relay Server status endpoint. `strelaysrv` exposes `/status` on port `22070` by default; the relay protocol itself uses port `22067`.
