### Supported metrics

| Widget section                | UGOS API source                       | May be unavailable                                                          |
| ------------------------------ | -------------------------------------- | ----------------------------------------------------------------------------- |
| CPU ring / chart               | `taskmgr/stat/get_all`                 | —                                                                             |
| CPU temperature ring           | `taskmgr/stat/get_all`                 | —                                                                             |
| Memory ring / chart            | `taskmgr/stat/get_all`                 | —                                                                             |
| Storage volume usage           | `sysinfo/storage/info`                 | —                                                                             |
| SMART status and temperature   | `v2/storage/disk/list`                 | Volumes spanning multiple disks (JBOD/RAID) and external USB disks           |
| Network charts                 | Not available                          | Always                                                                        |
| Load average (info modal)      | Not available                          | Always                                                                        |
| Reboot / update indicator      | Not available                          | Always                                                                        |
| GPU                            | Not available                          | Typical UGREEN NAS models                                                    |

<Alert type="note" title="Disk-to-volume matching">
  UGOS storage volumes can span more than one physical disk (for example a JBOD pool). Homarr can only show a single
  temperature and status per volume, so this is only reported when the underlying pool is made up of exactly one
  disk. Multi-disk volumes correctly show no temperature and an "N/A" status, matching the behavior of other
  multi-disk integrations such as TrueNAS and Unraid.
</Alert>

### Adding the integration

<Alert type="info" title="Include the port in the URL">
  Enter the full HTTPS URL of your UGOS web interface including the port, for example{" "}

</Alert>

<Alert type="info" title="Self-signed certificate">
  UGOS uses a self-signed certificate by default. The first connection attempt will prompt you to trust it; you can
  also add it manually under{" "}
  <a href="/docs/management/certificates">Management &gt; Tools &gt; Certificates</a>.
</Alert>
