### Secrets

<IntegrationSecrets secrets={[{ credentials: ["apiKey"], steps: ["Copy the API key from Jackett's dashboard."] }]} />

Jackett's API-key interface exposes configured indexers but does not provide their health history. The indexer widget displays “Health unavailable” for these entries. **Test all** performs an upstream Torznab search for each indexer and reports failures; it does not download results or change indexer configuration. Some indexers require a search query and may reject this generic test.

Statistics exposes the configured-indexer count. An error count is not available from this interface.
