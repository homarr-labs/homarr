### Secrets

Create an API key under **Immich user settings → API Keys** with these permissions:

`album.statistics`, `album.read`, `album.create`, `user.read`, `user.update`, `asset.read`, `asset.view`,
`asset.download`, `asset.statistics`, `server.statistics`, and `server.about`.
