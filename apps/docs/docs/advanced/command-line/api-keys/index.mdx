# API keys

Use these commands with a database connection through the [CLI](../) to bootstrap API access without a browser:

```bash
docker exec -it <container-id> homarr api-keys create --username admin
docker exec -it <container-id> homarr api-keys list
docker exec -it <container-id> homarr api-keys delete --id <key-id>
```

Creation accepts exactly one of `--username` (`-u`) or `--id` (`-i`), identifying the owner. The key inherits that user's
permissions. The complete `<id>.<token>` appears once; listing shows only key IDs and owners. Deletion takes the key ID,
which is the part before the dot. Failed creation or deletion exits with a nonzero status.

If no credentials administrator exists, run `homarr recreate-admin -u admin` first. Store the printed key securely and
send it in the `ApiKey` header. See [API automation](../../../management/api/) for authentication and import behavior.
