Homarr has the following keyboard shortcuts:

| Shortcut                                   | Description                                                |
| ------------------------------------------ | ---------------------------------------------------------- |
| `MOD` + `K`                                | Opens the search bar                                       |
| `MOD` + `J`                                | Toggles Dark Mode                                          |
| `MOD` + `E`                                | Toggles Edit Mode                                          |
| Hold `Shift` while hovering a widget       | Opens its temporary advanced view                          |
| `Shift` + `Enter` on a focused widget      | Opens and pins its advanced view                           |
| `Esc`                                      | Closes an open advanced view or board menu                 |
| `Shift` + `F10` on a focused board section | Opens the precise add-item menu at the next available cell |

:::tip

Here `MOD` refers to the modifier key, which is `Ctrl` on Windows and `Cmd` on macOS.

Advanced view and precise placement are available outside edit mode. Precise placement still requires permission to
change the board and the right-click interaction preference to be enabled.

:::

:::note

The focus of your browser must be set on Homarr. If you click outside of Homarr, you might need to click once somewhere in Homarr to send all keystrokes again to Homarr.

If the shortcuts are not working, ensure that you have selected the correct keyboard layout.

:::
