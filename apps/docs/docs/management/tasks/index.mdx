# Tasks

The tasks page controls scheduled background jobs used by integrations and widgets. It is available to administrators
under **Management → Tools → Tasks**.

Each task exposes:

- its current status and schedule;
- a cron-based schedule interval;
- a manual run action;
- an enable or disable action.

![The scheduled Tasks management page](../img/tasks.png)

Disabling a task stops scheduled runs but does not prevent a manual run.

The **Board preparation** task prepares recently used Board views after startup and every three hours. Live Widget data
continues refreshing on its usual schedule. If preparation fails or a Board changes, the Board loads through the normal
rendering path while a replacement is prepared. Access permissions are checked on every visit.
