# Custom JSX runtime

Templates are declarative JSX interpreted inside a widget-local error boundary. They cannot import modules or run arbitrary JavaScript.

## Data roots

```jsx
<Stack>
  <TextInput bind="search" label="Search TV shows" />
  <SubFetch requestId="search-series" params={{ query: state.search }} />
  {data["search-series"]?.map((series) => (
    <Group key={series.tvdbId}>
      <Text>{series.title}</Text>
      <ActionButton requestId="monitor-series" params={{ tvdbId: series.tvdbId }}>
        Monitor
      </ActionButton>
    </Group>
  ))}
</Stack>
```

- `data.<requestId>` contains sanitized JSON or text results.
- `status.<requestId>` contains loading, success, HTTP, and error state.
- `options` contains the validated board-item configuration.
- `state` contains browser-session local state.

Load-triggered queries populate data automatically and follow the widget refresh interval. `SubFetch` runs a manual query. `ActionButton` and `ToggleSwitch` invoke actions.

## Mantine capabilities

Homarr discovers exports from the installed Mantine Core, Dates, and Charts packages and generates prop metadata from their installed TypeScript definitions. Ordinary serializable props pass through. Style props, `style`, and `styles` are sanitized and scoped to the tile. Safe new Mantine exports become available without a hand-maintained allowlist; provider, portal, app-shell, modal, drawer, file, and low-level callback families are classified by the capability denylist.

Use safe Tabler icons through the resolver, for example `<TablerIcon name="server" size={18} />`. The editor completes installed icon names, and `homarr://custom-widgets/components/TablerIcon` exposes the same names to MCP agents.

The runtime blocks imports, hooks, refs, callbacks, polymorphic roots, provider replacement, arbitrary portal targets, browser networking, npm packages, evaluation, prototype-pollution keys, unsafe URLs, global selectors, and escaping CSS.

## Bindings

Declare state types and defaults, then bind controls:

```jsx
<TextInput bind="search" />
<Calendar bind="selectedDate" />
<Switch bind="enabled" />
<MultiSelect bind="selectedEntities" data={options.entities} />
```

Homarr adapts ordinary `value/onChange`, `checked/onChange`, `active/onChange`, and `opened/onChange` patterns plus documented unusual component signatures. State supports primitive values and `string[]`, `number[]`, or `date[]` for multi-value controls. Authored callbacks are not allowed.

## Diagnostics

- `BLOCKED_CAPABILITY`: unsafe behavior; saving fails.
- `UNKNOWN_COMPONENT`: the component does not exist; saving fails.
- `UNKNOWN_MANTINE_PROP`: advisory; the prop is passed through, not discarded.
- `INVALID_PROP_VALUE`: warning or error depending on safety.
- `BINDING_UNAVAILABLE`: the component renders, but `bind` is unavailable.
- `RUNTIME_RENDER_ERROR`: rendering failed inside this tile only.

Homarr never silently drops an ordinary prop.
