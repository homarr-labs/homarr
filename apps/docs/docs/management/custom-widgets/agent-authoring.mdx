## MCP discovery

- Prompt: `homarr-custom-widget-author`
- Resources: `homarr://custom-widgets/schema`, `components`, `components/{name}`, `examples/{name}`, and `skill`
- HTTP: `GET /api/custom-widgets/authoring-prompt` and `GET /api/custom-widgets/skill`

The authoring-prompt tool description intentionally contains only one sentence. Workflow instructions live in the prompt and link to resources.

## Agent loop

1. Fetch the prompt, live schema, and component catalog.
2. Read the external API documentation.
3. Build and validate one definition without saving.
4. Create a preview session and test its queries/actions.
5. Open the returned preview URL with browser tools.
6. Set a supplied credential with the dedicated secret-write permission, or ask the user through the ten-minute Homarr credential URL.
7. Inspect the redacted journal and patch until valid.
8. Create the widget, then repeat for the next requested widget.

Credential URLs are scoped to one definition/preview, source, and required fields. The agent receives only pending/completed status. Plaintext is encrypted immediately and never returned.
