          What this comparison includes
          
    
            Real worker proof, origin and capability checks, multiplexed channels and verified per-client replies.
            Opaque echo payloads exclude browser rendering, native API execution, integration calls and endpoint
            encryption. Separate relay and load-generator containers have enforced CPU/memory budgets. Local networking,
            short runs and a shared host limit what this says about production.
          
    
          
    
            * Higher-load latency is the maximum of individual generator-shard p99 values, not a pooled percentile. RSS
            is sampled process memory; main-row RSS is the median of per-run peaks. CPU is average relay cores during
            active traffic. Keep Bun as the default for now; the first Go port has higher CPU cost here. It preserves
            the wire protocol and remains useful for further profiling.
          
    
        
    
        
    
          Local networking matters. At 20,480 roundtrips/sec with 4KiB requests and replies, relay
          egress payload alone is 160MiB/sec. A 1Gbit/sec link carries about 119MiB/sec before overhead, so it cannot
          reproduce that echo workload. Real request and reply sizes differ.

                Potential failure
                What the user sees
                What fixes it
              
    
                
            
              
    
                Proxy/IP admission
                New connections rejected despite spare CPU.
                Trusted edge admission and per-worker budgets. Raising limits alone loses protection.
              
    
              
    
                Hot worker
                One installation drops many clients together.
                Align peer caps and reject only the excess channel; tune aggregate message budgets.
              
    
              
    
                Slow consumer / queued data
                Slow clients are disconnected; memory pressure rises.
                Bound total queued bytes and isolate slow tenants.
              
    
              
    
                Relay or worker saturated
                The connection stays open while widget requests stall.
                Bound queues, shed load and show the last successful worker response.
              
    
              
    
                Network / home uplink
                Widgets update slowly even with a fast relay.
                Measure egress, payload encoding and geographic RTT. Go cannot create more bandwidth.
              
    
              
    
                Multiple relay replicas
                Worker is registered but clients cannot find it.
                Route worker and clients to the same owner shard; coordinate reconnection on changes.
