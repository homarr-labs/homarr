# Homarr 2.0 — 30-second product cut

Shortens the previous 80-second film to 30 seconds. Product visuals are real screenshots and the release blog's drag-and-drop recording. Widget screenshots come from the earlier seeded UI audit; they are captured demo data, not live readings. Motion includes opposing widget rows, a logo wall, camera reframing and close-ups. No simulated Assistant conversation or fabricated widget controls.

0–3 dashboard; 3–9 actual drag recording; 9–13 widget captures; 13–16 integrations; 16–19 Assistant; 19–23 custom widget preview; 23–27 Workshop; 27–30 closing.

Rebuild HTML: `python3 brag-output/build-short.py`. Render from this directory using `npm run render -- --quality delivery --fps 30 --output ../brag-short.mp4`.

Music uses the existing project track and its existing license notes. Original 80-second version remains unchanged.
