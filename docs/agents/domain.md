# Domain Docs

Before exploring Homarr, read the root `GLOSSARY.md` and relevant decisions in
`docs/adr/`, when present.

Use the glossary's terms for domain concepts in issues, proposals and code
discussions, respecting its `_Avoid_` guidance. Note genuine vocabulary gaps for
`/domain-modeling`.

When proposing a change that contradicts an ADR, identify the decision and explain
why it should be reconsidered.
