## Retained and deferred findings

| Candidate                                                   | Decision and evidence                                                                                                                                                                                                  |
| ----------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Parallel manual-source metadata with load requests          | Rejected: metadata shares the four-active-request item capacity and cannot wait; racing it against loads can turn previously successful metadata into `unavailable`. Preserve ordering.                                |
| Wider integration permission/credential caching             | Rejected: authorization must precede warm response-cache access. New maps end with one invocation; later invocations re-read database state. Revocation and cross-user denial were manually verified.                  |
| Connection/DNS pooling                                      | Deferred: per-request pinned addresses, TLS settings, credential isolation and deadlines need separate proof before changing dispatcher reuse.                                                                         |
| Pi-hole session reuse                                       | Deferred: generic HTTP currently lacks authentication-failure retry, so cached session expiry could change behavior. Adapter-owned auth remains native.                                                                |
| Redis/request-handler cache rewrites                        | No justified new change: current code already has bounded L1/cache expiry, generation reads/coalescing and lock renewal. Retain invalidation contracts. Small pub/sub serialization was not a demonstrated bottleneck. |
| Cross-request stored-definition/schema cache                | Deferred: returned definitions are mutable, and auth/secret/freshness boundaries make broad caching unsafe without a stronger interface.                                                                               |
| Renderer boundary serialization/hash                        | Retained: content-based keys drive equivalent-data error recovery. A cheaper identity-only key changes those semantics; no such substitution made.                                                                     |
| Plain versus input-bound runtime wrappers; emitter contexts | Deferred pending actual React profiling and markup proof. Avoid expanding the implementation merely to remove small allocations.                                                                                       |
| Splitting Mantine Core/Charts/Dates runtime imports         | Deferred: existing dynamic widget loading remains enforced; a larger component-loader redesign needs production bundle evidence.                                                                                       |
